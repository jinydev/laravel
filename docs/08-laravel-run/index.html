08. 라라벨 실행 - Hello World와 같은 첫 걸음

안녕하세요! 이제 드디어 Laravel을 실행해볼 시간입니다. 이것은 프로그래밍에서 “Hello World”를 출력하는 것과 정확히 같은 의미입니다. 첫 번째 프로그램을 실행하고 화면에 무언가가 나타나는 것을 보는 것, 그 기쁨을 지금 경험하실 거예요!

💡 강의 노트: Laravel 서버를 실행하는 것은 마치 전등의 스위치를 켜는 것과 같습니다. 스위치를 켜면 빛이 나오듯이, 서버를 실행하면 웹 페이지가 나타납니다.

🎯 이번 강의에서 배울 것

이번 강의를 마치면 여러분은:

  • ✅ Laravel 개발 서버를 실행할 수 있습니다
  • ✅ 브라우저에서 Welcome 페이지를 볼 수 있습니다
  • ✅ 서버가 어떻게 작동하는지 이해할 수 있습니다
  • ✅ 개발 환경이 제대로 설정되었는지 확인할 수 있습니다

🚀 Laravel 서버 실행하기

왜 서버를 실행해야 하나요?

웹 애플리케이션은 서버가 있어야 작동합니다. 마치 TV가 전원이 켜져야 화면이 나오는 것과 같아요.

  • 로컬 개발 서버: 개발 중인 웹사이트를 컴퓨터에서 바로 확인할 수 있게 해줍니다
  • 실시간 반영: 코드를 수정하면 바로 브라우저에서 확인할 수 있습니다
  • 디버깅: 에러가 발생하면 화면에 바로 표시되어 문제를 쉽게 찾을 수 있습니다

1단계: 프로젝트 디렉토리로 이동

먼저 Laravel 프로젝트가 있는 폴더로 이동해야 합니다.

# 프로젝트 디렉토리로 이동
# 예: cd jinyphp_demo_01
cd [프로젝트 폴더 이름]

🔍 확인 방법: ls 명령어로 현재 폴더의 파일을 확인해보세요. artisan 파일이 보이면 올바른 위치입니다!

💬 설명:

  • cd는 “change directory”의 약자로, 폴더를 이동하는 명령어입니다
  • 프로젝트 폴더 이름은 여러분이 Laravel을 설치할 때 정한 이름입니다
  • artisan 파일은 Laravel의 핵심 도구로, 여러 명령어를 실행할 수 있게 해줍니다

2단계: 개발 서버 실행

이제 Laravel의 개발 서버를 실행해봅시다! 매우 간단합니다.

# Laravel 개발 서버 실행
php artisan serve

실행하면 다음과 같은 메시지가 나타납니다:

   INFO  Server running on [http://127.0.0.1:8000]

  Press Ctrl+C to stop the server

🎉 축하합니다! 서버가 성공적으로 실행되었습니다! 이제 브라우저에서 웹사이트를 볼 수 있어요.

💬 설명:

  • php artisan serve는 Laravel의 내장 개발 서버를 실행하는 명령어입니다
  • http://127.0.0.1:8000은 서버 주소입니다 (localhost:8000과 같습니다)
  • Ctrl+C를 누르면 서버를 중지할 수 있습니다

3단계: 브라우저에서 확인하기

이제 브라우저를 열어서 Welcome 페이지를 확인해봅시다!

  1. 웹 브라우저 열기 (Chrome, Firefox, Safari 등)
  2. 주소창에 입력: http://localhost:8000 또는 http://127.0.0.1:8000
  3. Enter 키 누르기

화면에 나타나는 것:

  • 🎨 아름다운 Laravel Welcome 페이지
  • “Laravel” 로고와 함께 환영 메시지
  • Laravel 버전 정보
  • 여러 유용한 링크들

🌟 첫 번째 성공! 여러분은 이제 Laravel 웹 애플리케이션을 실행했습니다! 이것은 정말 큰 첫 걸음입니다.

📖 Welcome 페이지 이해하기

Welcome 페이지는 무엇인가요?

Welcome 페이지는 Laravel이 설치되었을 때 기본으로 보여주는 페이지입니다. 마치 새 집에 들어갔을 때 보는 안내판과 같다고 생각하시면 됩니다.

Welcome 페이지의 의미:

  • ✅ Laravel이 제대로 설치되었음을 확인
  • ✅ 개발 환경이 올바르게 설정되었음을 확인
  • ✅ 서버가 정상적으로 작동하고 있음을 확인
  • ✅ 다음 단계로 넘어갈 준비가 되었음을 알림

Welcome 페이지의 구성 요소

Welcome 페이지를 자세히 살펴보면:

  1. 헤더 (Header)
    • Laravel 로고
    • 프레임워크 이름과 버전 정보
  2. 메인 콘텐츠 (Main Content)
    • 환영 메시지
    • Laravel에 대한 간단한 소개
  3. 링크 섹션 (Links Section)
    • Laravel 문서 링크
    • Laracasts (비디오 튜토리얼) 링크
    • Laravel News 링크
    • 생태계 링크
  4. 푸터 (Footer)
    • Laravel 버전 정보
    • PHP 버전 정보

🔧 서버 실행 옵션

포트 번호 변경하기

기본 포트(8000)가 사용 중이거나 다른 포트를 사용하고 싶다면:

# 8080 포트로 서버 실행
php artisan serve --port=8080

💬 설명:

  • --port 옵션으로 원하는 포트 번호를 지정할 수 있습니다
  • 포트 번호는 1024 이상의 숫자를 사용하는 것이 좋습니다
  • 브라우저에서는 http://localhost:8080으로 접속하면 됩니다

호스트 주소 변경하기

네트워크의 다른 기기(스마트폰, 태블릿 등)에서도 접속하고 싶다면:

# 모든 네트워크 인터페이스에서 접속 가능하도록 설정
php artisan serve --host=0.0.0.0

💬 설명:

  • --host=0.0.0.0으로 설정하면 같은 네트워크의 다른 기기에서도 접속할 수 있습니다
  • 접속 주소는 http://[컴퓨터의 IP 주소]:8000입니다
  • 예: http://192.168.0.10:8000

⚠️ 보안 주의: 개발 환경에서만 사용하세요! 프로덕션 환경에서는 절대 사용하지 마세요.

포트와 호스트를 함께 지정하기

포트와 호스트를 동시에 지정할 수도 있습니다:

# 포트 8080, 호스트 0.0.0.0으로 실행
php artisan serve --host=0.0.0.0 --port=8080

🛑 서버 중지하기

서버를 중지하는 방법

서버를 중지하려면:

  1. 터미널 창으로 돌아가기
  2. Ctrl + C 키를 누르기 (Mac: Cmd + C)

서버가 중지되면 다음과 같은 메시지가 나타납니다:

^C

💡 팁: 서버를 중지해도 프로젝트 파일은 그대로 남아있습니다. 언제든지 다시 실행할 수 있어요!

🐛 문제 해결

자주 발생하는 문제들

문제 1: “포트가 이미 사용 중입니다” 오류

증상:

Error: Address already in use

해결 방법:

# 다른 포트로 실행
php artisan serve --port=8080

# 또는 사용 중인 프로세스 종료 (Mac/Linux)
lsof -ti:8000 | xargs kill

# Windows의 경우
netstat -ano | findstr :8000
taskkill /PID [프로세스 ID] /F

문제 2: “artisan 파일을 찾을 수 없습니다” 오류

증상:

Could not open input file: artisan

해결 방법:

  • Laravel 프로젝트 디렉토리로 이동했는지 확인
  • ls 명령어로 artisan 파일이 있는지 확인
  • 올바른 프로젝트 폴더인지 확인

문제 3: “PHP를 찾을 수 없습니다” 오류

증상:

'php' is not recognized as an internal or external command

해결 방법:

  • PHP가 설치되어 있는지 확인: php -v
  • PHP가 PATH에 추가되어 있는지 확인
  • PHP를 재설치하거나 PATH를 설정

문제 4: 브라우저에서 페이지가 로드되지 않음

해결 방법:

  1. 서버가 실행 중인지 확인 (터미널에서 확인)
  2. 올바른 주소를 입력했는지 확인 (http://localhost:8000)
  3. 방화벽 설정 확인
  4. 다른 브라우저로 시도
